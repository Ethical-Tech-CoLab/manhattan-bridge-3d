# Source Register

Authoritative index of every source that may influence geometry in this repository.

**Rules**

1. No geometry may be promoted above confidence `D` without at least one registered source ID.
2. A source ID may be cited at any time, but its `Verified` state is tracked. A control value whose sources are **all** unverified is reported as `verification_pending` by `scripts/validate_dimensions.py` and may not advance past `agent_reviewed`. Verification gates review status; it does not by itself change a confidence grade.
3. URLs are recorded as `TBD (unverified)` until a human or a network-enabled agent run confirms the exact locator. This repository does not fabricate citations.
4. Tier C meshes are never authoritative. See [AGENT-INSTRUCTIONS.md](/c:/Dev/manhattan-bridge-3d/AGENT-INSTRUCTIONS.md) section 3.
5. **Citation chain.** When a value is read from a source that is itself quoting a primary document, both are recorded and the value is capped at `B` until the primary is examined directly. A value is graded `A` only when the source stating it was examined directly during this repository's own research.
6. **LLM-synthesised search answers are not sources.** Retrieval tools that return a generated summary (for example the Tavily `answer` field) may be used to *locate* documents, never to *supply* a dimension.
